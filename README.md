# crunchit-app

CrunchIt converts JPG and PNG images in your browser.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FJsIsEasy%2Fcrunchit-app&root-directory=storefront)

The button imports this GitHub repository into a new Vercel project with `storefront` as its root directory. The Go backend runs separately.
