# CrunchIt identity

The geometric C frames a separate diamond, representing a file taking a new form.
The mark is drawn as filled vectors so it remains clear in small sizes and in print.

- Primary mark: `mark.svg`, emerald on a transparent background.
- App icons: dark navy background with the emerald mark.
- Wordmark: Space Grotesk, weight 600. Preserve the capital C and I in CrunchIt.
- Colours: emerald `#4AF0B5`, navy `#0B151B`, off-white `#EDF6F5`.
- Minimum mark size: 24 px in the interface; use the app icon for browser tabs.
- Leave clear space around the mark of at least the diamond's width.
- Keep the mark upright. Do not add a badge, glow, gradient, outline, or shadow.

The header lockup lives in `src/components/ui/logo.tsx`.
The browser icon and manifest use Next.js file metadata conventions.
